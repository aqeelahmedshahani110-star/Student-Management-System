# Student Management System

A Student Management System developed using Java, JDBC and MySQL.

## Technologies Used

- Java
- JDBC
- MySQL

## Features

- Add Student
- View Students
- Update Student
- Delete Student
- Search Student
  
## Course Management
- Add Course
- View Course

## Database

MySQL is used to store student information.

## How to Run

1. Install Java.
2. Install MySQL.
3. Create the `student_management` database.
4. Configure the JDBC connection.
5. Run `Main.java`.
